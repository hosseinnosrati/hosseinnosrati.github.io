Non-contact wireless cardiopulmonary telemetry extracting respiration and heart rates from 5.8 GHz RF phase shifts and Wi-Fi Channel State Information (CSI). Incorporates carrier frequency offset (CFO) regression and dual-band IIR decomposition to isolate sub-millimeter apex beat vibrations.

RF Sensing Wi-Fi CSI Doppler Phase Sanitization Micro-Motion Decomposition

IoT-Compressive-Sensing →

Energy-efficient sub-Nyquist Compressive Sensing (CS) telemetry pipeline for wearable IoMT sensor nodes. Reduces on-air RF transmission payload by 50% to 70% using random sub-Gaussian projections on-node and gateway Orthogonal Matching Pursuit (OMP) sparse recovery in DCT basis.

Compressive Sensing Sub-Nyquist OMP Recovery IoT Telemetry CRC-16
Benchmark: 0.005 ms/block node encoding | 0.24% PRD clinical error (<2% standard) | 52.3 dB SNR
